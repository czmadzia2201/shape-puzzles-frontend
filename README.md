# ShapePuzzles Frontend

Angular frontend for the ShapePuzzles project.

While Angular provides the application framework, at the core of its mechanics is **Konva.js**. It's responsible for rendering task shapes, puzzle pieces and the whole game playground, and for handling user interactions: dragging, rotating, flipping and snapping.

The backend repository, together with the complete project description, architecture overview and setup instructions, can be found here:

**Backend:** https://github.com/czmadzia2201/shape-puzzles-backend

For more information about the project, please refer to the backend README.
